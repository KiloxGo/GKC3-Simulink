# 公开发布说明

本仓库是协作项目的整理发布版，以独立 Git 历史维护。成员署名集中于 README 与 CONTRIBUTORS，使用维护者确认的六个 GitHub 用户名。

## 文件范围

公开内容包括模型、组件源码、运行脚本、导出数据、模型视图、技术报告与说明。原课堂指导书、聊天截图、旧提交记录、个人封面和内部审计映射不分发。报告技术正文保留，封面与页眉改为中性项目样式。

模型与信号的技术名称、数值和控制逻辑保留；身份元数据在副本中清理。第三方软件的必要版权与许可不作为个人隐私删除。

原始仿真会话 MAT 与可编辑 FIG 通过脚本在本地重建。已导出的 CSV、PNG、PDF 与指标可直接使用。

## 持续检查

`tools/check_repository.py` 检查公开文件、身份元数据、常见私人路径、文件尺寸、关键数据和本地文档链接。GitHub Actions 执行同样的检查。该检查不是任意敏感信息的完备识别器；提交者仍需检查新增截图与文本。

账号署名会链接到成员的公开 GitHub 主页。本项目清理的是交付文件中的个人信息，不承诺账号层面的匿名性。
